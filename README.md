cgpa calculator:

A simple C++ console-based CGPA Calculator developed as part of the CodeAlpha C++ Internship.
Project Description:
This program calculates the GPA for each semester and the final CGPA based on the grade points and credits entered for each course.
The user can enter multiple semesters, with a different number of courses in each semester.
 Features:
- Enter the number of semesters
- Enter the number of courses for each semester
- Enter grade points for each course
- Enter credits for each course
- Calculate semester GPA
- Display total credits and grade points for each semester
- Display grades for all semesters
- Calculate and display the final CGPA
- Results are displayed up to 2 decimal places
Technologies Used:
- Language: C++
- Concepts Used:
  - Arrays
  - Loops
  - Functions
  - Variables
  - Arithmetic operations
  - Formatted output

How to Run:

1. Clone or download this repository.
2. Open "cgpa.cpp" in a C++ compiler.
3. Compile the program.
4. Run the program.
5. Enter the semester, course, grade point, and credit details.
6. The program will display the semester GPA and final CGPA.

CGPA Calculation:

The GPA for each semester is calculated using:
GPA = Total Grade Points / Total Credits       
The final CGPA is calculated using:
CGPA = Total Grade Points of All Semesters / Total Credits of All Semesters
